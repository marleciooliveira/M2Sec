# M3Sec — Remoção e Desindexação de Dados Pessoais

Negócio de reputação digital: remoção e desindexação de informações pessoais na internet, com duas frentes regulatórias diferentes.

- **Europa** — pedidos de apagamento com base no GDPR (art. 17, direito ao apagamento).
- **Brasil** — desindexação/remoção de resultados do Google, de plataformas agregadoras de processos judiciais (Escavador, JusBrasil) e de notícias com dados sensíveis, com base na LGPD.

Documentos:
- [`modelo-negocio.md`](modelo-negocio.md) — tese, segmentação, divisão por risco jurídico, monetização, fases.
- [`plano-marketing.md`](plano-marketing.md) — persona, posicionamento, canais, funil.

Ambos são rascunho de discussão, não plano fechado — mesmo estágio e mesmo formato usado no projeto [Imersão](https://github.com/marleciooliveira/Imersao).
